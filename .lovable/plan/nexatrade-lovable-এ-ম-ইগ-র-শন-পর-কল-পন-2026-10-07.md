# NexaTrade — Lovable-এ মাইগ্রেশন পরিকল্পনা

## অবস্থা

আপনার GitHub রিপোজিটরি (`NexaTrade-migration-project-2.0`) ডাউনলোড করা হয়েছে এবং `/tmp/nexatrade-import`-এ সংরক্ষিত আছে। এটি একটি বড় ট্রেডিং প্ল্যাটফর্ম:

- ৩২টি পৃষ্ঠা (ল্যান্ডিং, লগইন/সাইনআপ, ড্যাশবোর্ড, ট্রেডিং টার্মিনাল, KYC, ওয়ালেট, অ্যাডমিন পোর্টাল ইত্যাদি)
- ৭৭টি সার্ভার API (লগইন, ট্রেড, পেমেন্ট, KYC, অ্যাডমিন রিস্ক ইঞ্জিন)
- PostgreSQL ডেটাবেস, JWT-ভিত্তিক নিজস্ব লগইন সিস্টেম

## সমস্যা

অ্যাপটি **Next.js**-এ তৈরি, কিন্তু Lovable-এ শুধু **TanStack Start** (React) চলে। তাই কোডটি হুবহু কপি করা যাবে না — প্রতিটি অংশ ধাপে ধাপে রূপান্তর করতে হবে। এক বার্তায় পুরোটা সম্ভব নয়; নিচের ধাপগুলোতে এগোবো।

## ধাপসমূহ

### ধাপ ১ — ভিত্তি (এই ধাপে)

- Lovable Cloud চালু করা (ডেটাবেস + লগইন সিস্টেম বিল্ট-ইন)
- NexaTrade-এর ডিজাইন সিস্টেম (রং, ফন্ট, গাঢ় থিম) `src/styles.css`-এ বসানো
- হোমপেজ (ল্যান্ডিং) তৈরি — মূল অ্যাপের লুক অনুসারে

### ধাপ ২ — অ্যাকাউন্ট

- সাইনআপ / লগইন পৃষ্ঠা (Lovable Cloud auth দিয়ে)
- ড্যাশবোর্ডের মূল কাঠামো

### ধাপ ৩ — ট্রেডিং

- ট্রেডিং টার্মিনাল (চার্ট, অ্যাসেট তালিকা, ট্রেড করা)
- ওয়ালেট / হিস্টোরি

### ধাপ ৪ — অ্যাডমিন ও বাকি সব

- অ্যাডমিন পোর্টাল (ইউজার, KYC, ফাইন্যান্স, রিস্ক)
- About / Contact / Terms / Privacy পৃষ্ঠা

## টেকনিক্যাল নোট

- মূল কোডের `src/components`, `src/lib`, CSS ফাইলগুলো রেফারেন্স হিসেবে ব্যবহার হবে; UI যতটা সম্ভব হুবহু রাখা হবে।
- Next.js API রুটগুলো TanStack Start server function-এ রূপান্তর হবে; Postgres টেবিল Lovable Cloud মাইগ্রেশনে আসবে।
- মূল রিপোর `.base44`, Docker, Vercel/Render কনফিগ Lovable-এ প্রযোজ্য নয় — বাদ যাবে।
