# TRADEON — ডাটাবেসের কপ (database-export)

এই ফোল্ডারটোত আপনার প্ল্যাটফরমের **লাইভ তথ্যের কপ** আছ। কোড ছাড়া যে তথ্য
গিটহাবে থাকত না, সেগুলা এখানে রাখা হইছে — যেন এক জায়গাতেই সব থাকে।

## কী কী আছ

| ফাইল | ভিতরত কী |
| --- | --- |
| `schema.sql` | টেবিলগুলাের গঠন (কোন টেবিলে কোন কলাম, কী রকম নিয়ম) |
| `data.sql` | সেই টেবিলগুলাের ভিতরত জমা তথ্য — ২৫টা টেবিল |

`data.sql`-এ যে তথ্য আছ (সারি সংখ্যাসহ):

- `users` — ২৫ (সব অ্যাকাউন্ট: ইউজার, লিডার, অ্যাডমিন, সুপার অ্যাডমিন)
- `markets` — ১৫২ ও `assets` — ১৫২ (মার্কেট ক্যাটালগ)
- `otc_instruments` — ৩৬১ (OTC ট্রেডিং তালিকা), `otc_market_state` — ৩৬২ (বর্তমান দাম/অবস্থান), `otc_engine_config` — ১
- `system_settings` — ১ (মিনিমাম ডিপোজিট, KYC নিয়ম, টাইমারের রঙ — সব অ্যাডমিন সেটিংস)
- `vip_tiers` — ৩, `payment_methods` — ৬ (জমার/তোলার পদ্ধতি)
- `tournaments` — ৮, `copy_links` — ৮, `notifications` — ২৪
- `affiliate_applications` / `affiliate_commissions` — ৮ করে, `kyc_submissions` — ৮
- `trades` — ৮, `security_logs` — ৩৮, `otc_engine_events` — ৭২৭, `platform_events` — ১

খালি টেবিলের কপিতো শুধু গঠন আছে, তথ্য নাই (যেমন `transactions`,
`tournament_entries`, `affiliate_payouts`) — সেখানে এখনো তথ্য জমা হয় নাই।

## যা সইচ্ছাকৃতভাবে নেওয়া হয় নাই

দুইটা বিশাল টেবিল — `otc_price_ticks` (১,৭০,৭৯৬ সারি, ~১৮৪ মেগা) আর
`otc_candles` (১,২৯,৬২৫ সারি, ~১৫১ মেগা) — কপিতো রাখা হয় নাই। এগুলা চার্টের
প্রতি সেকেন্ডের হিসাব, আর সার্ভার চালালেই নুতন করে তৈরি হতে থাকে। পুরনো
ইতিহাসও সার্ভার নীজ থেকেই বানিয়ে দেখায়।

## অন্য জায়গাতে বসানোর নিয়ম

১. একটা ফাঁকা PostgreSQL (সংস্করণ ১৫ বা ওপরে) খুলুন।
২. গঠন বসান:

   ```bash
   psql "আপনার-ডাটাবেসের-ঠিকানা" -f schema.sql
   ```

৩. তথ্য বসান:

   ```bash
   psql "আপনার-ডাটাবেসের-ঠিকানা" -f data.sql
   ```

৪. `tradeon/server/.env` ফাইলে `DATABASE_URL`-এ সেই ঠিকানা দিন, তারপর সার্ভার
   চালু করুন (`bun install`, তারপর `npx tsx src/index.ts`)।

> `schema.sql` আর `data.sql` এই ক্রমেই চালাতে হয়, আর `data.sql` চালানোর আগে
> টেবিলগুলা ফাঁকা থাকতে হয়।

## সতর্কতা

`data.sql`-এ অ্যাকাউন্টের ইমেইল, ফোন, পাসওয়ার্ডের কুঁজি (hash), দুই ধাপের
গোপন চাবি (TOTP) আর KYC-এর তথ্য আছে। তাই এই রিপো কখনো **সবার জন্য খোলা
(public) রাখবেন না** — সবসময় নিজি (private) রাখুন।
