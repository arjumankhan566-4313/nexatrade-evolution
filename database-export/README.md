# TRADEON — ডাটাবেসের কপি (database-export)

এই ফোল্ডারটোত আপনার প্ল্যাটফর্মের **লাইভ তথ্যের কপি** আছ। কোড ছাড়া য়ে তথ্য
গুটহাবে থাকত না, সেগুলো এখানে রাকহ য়াত এক কপি ফাইলে সব থাকে।

## কি কি আছ

| ফাইল | ভেতরত কী |
| --- | --- |
| `schema.sql` | টেবিলগুলোর গঠন (কোন টেবিলে কোন কলাম, কী রকম নিয়ম) |
| `data.sql` | সেই টেবিলগুলোর ভেতরত জমা তথ্য — ২৫টা টেবিল |

`data.sql`-এ য়ে তথ্য আছ (সারি সংখ্যাসহ):

- `users` — ২৫ (সব অ্য্যাকাউন্ট: ইউজার, লিডার, অ্য্যামিন, সুপার অ্য্যামিন)
- `markets` — ১৫২ ও `assets` — ১৫২ (মার্কেট ক্যাতালগ)
- `otc_instruments` — ৩৬১ (OTC ট্রেডিং তালিকা), `otc_market_state` — ৩৬২ (বর্তমান দাম/অবস্থান), `otc_engine_config` — ১
- `system_settings` — ১ (মিনিমাম ডিপোজিট, KYC নিয়ম, টাইমারের রঙ — সব অ্য্যামিন সেটিংস)
- `vip_tiers` — ৩, `payment_methods` — ৬ (জমার/তোলার পদ্ধতি)
- `tournaments` — ৮, `copy_links` — ৮, `notifications` — ২৪
- `affiliate_applications` / `affiliate_commissions` — ৮ করে, `kyc_submissions` — ৮
- `trades` — ৮, `security_logs` — ৩৮, `otc_engine_events` — ৭২৭, `platform_events` — ১

খালি টেবিলের কপিতো শুধু গঠন আছ, তথ্য নাই (যেমন `transactions`,
`tournament_entries`, `affiliate_payouts`) — সেখান এখন তথ্য জম নাই।

## যা故意তরূপে নেওয়া হয় না

দুইটা বিশাল টেবিল — `otc_price_ticks` (১,৭০,৭৯৬ সারি, ~১৮৪ মেগা) আর
`otc_candles` (১,২৯,৬২৫ সারি, ~১৫১ মেগা) — কপিতো **রাকহ না**। এগুলো চার্টের
প্রতি সেকেন্ডের দামের হিসাব, আর সার্ভার চালু হলে নিজে থেকেই নতুন করে তৈরি হতে
থাকে। পুরনো ইতিহাসও সার্ভার নিজে থেকেই বানিয়ে দেখায়।

## অন্য জায়গায় বসানোর নিয়ম

১. একটা ফাঁকা PostgreSQL (সংস্করণ ১৫ বা ওপরে) খুলুন।
২. গঠন বসান:

   ```bash
   psql "যে-ঠিকানা-আপনার-ডাটাবেসের" -f schema.sql
   ```

৩. তথ্য বসান:

   ```bash
   psql "যে-ঠিকানা-আপনার-ডাটাবেসের" -f data.sql
   ```

৪. `tradeon/server/.env` ফাইলে `DATABASE_URL`-এ সেই ঠিকানা দিন, তারপর সার্ভার
   চালু করুন (`bun install`, তারপর `npx tsx src/index.ts`)।

> `schema.sql` আর `data.sql` একই ক্রমে চালাতে হবে, আর `data.sql` চালাবার আগে
> টেবিলগুলো ফাঁকা থাকতে হবে।

## সাবধান

`data.sql`-এর ভেতরত অ্য্যাকাউন্টের ইমেইল, ফোন, পাসওয়ার্ডের কুঁজি (hash),
দুই ধাপের গোপন কী (TOTP) আর KYC-এর তথ্য আছ। তাই এই রিপো কখনো **সবার জন্য
খোলা (public) রাখবেন না** — সবসময় নিজি (private) রাখুন।
